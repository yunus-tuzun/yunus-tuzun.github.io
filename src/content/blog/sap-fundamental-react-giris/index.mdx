> İlk olarak Temmuz 2019'da [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-members/fundamentals-for-sap-fiori-applications-intro/ba-p/13393138) üzerinde yayımlandı. Kütüphane sürümleri ve API'ler o tarihten bu yana değişti.

SAP Fundamental, Fiori uygulamalarını tercih edilen UI framework'üyle geliştirmeyi mümkün kılıyor: React, Vue ya da Angular. Uygulamalar standart web teknolojileri ve açık kaynak npm kütüphaneleriyle yazılıyor; bu da daha esnek bir yapı ve geniş JavaScript ekosistemine erişim sağlıyor.

Fundamental, UI5'in yerini almıyor. UI5 tarafındaki geliştirme devam ediyor; Fundamental yalnızca Fiori geliştiricilerinin tek bir teknolojiye bağlı kalmadığı anlamına geliyor.

- Proje sayfası: [sap.github.io/fundamental](https://sap.github.io/fundamental/index.html)
- React: [sap.github.io/fundamental-react](https://sap.github.io/fundamental-react)
- Angular: [sap.github.io/fundamental-ngx](https://sap.github.io/fundamental-ngx)
- Vue: [sap.github.io/fundamental-vue](https://sap.github.io/fundamental-vue)

## Basit bir React uygulaması

Bir React projesi için paket yöneticisi gerekiyor. En yaygını npm (Yarn da çalışır); JavaScript'i tarayıcı dışında çalıştıran [Node.js](https://nodejs.org/en/) ile birlikte geliyor.

Node.js kurulduktan sonra uygulama bir terminalden (örneğin Visual Studio Code içinden) oluşturulur ve klasörüne geçilir:

```bash
npx create-react-app <project-name>
cd <project-name>
```

Fundamental stilleri ve React bileşenleri kurulur:

```bash
npm install fundamental-styles fundamental-react
```

Projede artık üç klasör var:

- `node_modules`: kütüphane dosyaları
- `public`: dış erişime açık dosyalar
- `src`: kaynak dosyalar

## Başlık, metin ve buton içeren bir panel

`App.js` içinde, dosyanın başında bileşenler import edilir:

```jsx
import { Panel } from 'fundamental-react/Panel';
import { Button } from 'fundamental-react/Button';
```

`App` div'inin içindeki her şey silinir ve şu eklenir:

```jsx
<Panel>
  <Panel.Header>
    <Panel.Head description="New Fundamental App" title="Fiori 3.0 with React" />
    <Panel.Actions>
      <Button compact glyph="add">
        Add Item
      </Button>
    </Panel.Actions>
  </Panel.Header>

  <Panel.Body>Open-source, New UI</Panel.Body>
</Panel>
```

Uygulama `npm start` ile başlatılır.

Örnek kod [GitHub](https://github.com/yunustuzun/sap-fundamental) üzerinde. React kütüphanesi hakkında daha fazla bilgi almak ya da katkıda bulunmak için: [sap/fundamental-react](https://github.com/sap/fundamental-react).

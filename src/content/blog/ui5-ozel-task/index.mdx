> İlk olarak Mayıs 2021'de [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-members/ui5-custom-task-creation-and-usage/ba-p/13498929) üzerinde yayımlandı.

[UI5 Tooling](https://sap.github.io/ui5-tooling/) içinde bir custom task, build sürecine ek işlemler ekliyor. Bu demo, projede kullanılmayan i18n metinlerini temizliyor; proje dosyaları farklı workspace'lerden birleştirildiğinde ve birçok i18n metni gereksiz hale geldiğinde zaman kazandırıyor.

## Task yapılandırması

`ui5.yaml` içinde custom task, göreli olarak çalışacağı standart task ile birlikte tanımlanıyor. Burada `replaceCopyright` öncesinde çalışıyor:

```yaml
builder:
  customTasks:
    - name: cleanUnusedi18nKeys
      beforeTask: replaceCopyright
---
# Task extension as part of your project
specVersion: "2.1"
kind: extension
type: task
metadata:
  name: cleanUnusedi18nKeys
task:
  path: tasks/cleanUnusedi18nKeys.js
```

## Task dosyası

Task dosyası async bir fonksiyon export ediyor. `workspace` nesnesi proje dosyalarına erişim sağlıyor:

```js
module.exports = async function ({ workspace, dependencies, taskUtil, options }) {
  // ...
};
```

## Mantık

Her i18n anahtarı proje dosyalarında (controller, fragment, view ve manifest) aranıyor. Bulunamayan anahtarlar yeni i18n dosyasına alınmıyor. Adımların sırayla çalışması için her async çağrı await ediliyor.

```js
const textResources = await workspace.byGlob("**/*{view.xml,fragment.xml,controller.js,manifest.json}");
const i18nFiles = await workspace.byGlob("**/*.properties");
// ...
await Promise.all(i18nFiles.map(async (i18nFile) => {
  // ...
  lines = lines.filter((l) => l.found === true);

  for (let i = 0; i < lines.length; i++) {
    line = lines[i];
    i18nString += line.key + " = " + line.value + "\n";
  }
  i18nString.substring(0, i18nString.length - 2);

  await i18nFile.setString(i18nString);

  await workspace.write(i18nFile).then(() => console.log('DONE'));
  // ...
}));
```

## Sonuç

`ui5 build` sonrasında, workspace'in hiçbir yerinde kullanılmayan i18n anahtarları build çıktısından kalkmış oluyor.

## Son söz

Kodun tamamı, custom task geliştirmek için referans olarak [GitHub](https://github.com/Yunustuzun/UI5-i18n-cleaner) üzerinde; ek gereksinimler için [API referansına](https://sap.github.io/ui5-tooling/api/index.html) bakılabilir. Babel ya da Grunt.js gibi kütüphaneler de bir task içinde kullanılabiliyor.

Custom task'lar, build öncesinde ya da sırasında dosyaları formatlayabiliyor, transpile edebiliyor ya da lint'ten geçirebiliyor. [UI5 Ecosystem](https://github.com/ui5-community/ui5-ecosystem-showcase) katkıcıları sayesinde yaygın ihtiyaçları karşılayan birçok hazır task zaten mevcut.
